# Donkey TV

Android TV shell app for https://donkey.to - WebView based, D-pad friendly, ad domains blocked.

Push this folder to a private GitHub repo, open the Actions tab, download the DonkeyTV-apk artifact.
Install with the Downloader app or: adb connect TV_IP:5555 then adb install app-debug.apk

Controls: D-pad moves focus, OK opens/plays, long-press OK toggles a mouse cursor,
MENU opens options, BACK exits fullscreen / goes back / double-press to quit.
